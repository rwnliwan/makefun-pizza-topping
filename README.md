## The entry

> Try our melatonin pizza: one slice and you wake up tomorrow, still holding the box.

83 characters (Python `len()`). The topping is terrible because of its
effect, not its taste: melatonin puts you to sleep, so one slice ends
your evening before it starts — and you wake up still holding the box.

## How it runs

`main.ts` writes the line to `/output/entry.txt`. No network, no
arguments, no dependencies.

```
node main.ts
```
